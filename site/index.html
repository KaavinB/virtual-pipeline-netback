Should this gas be trucked, or burned?

Oil wells in West and South Texas also produce natural gas. Where no pipeline can take it, producers often flare it (burn it on site) and earn nothing. A virtual pipeline puts that gas on trucks instead (compressed as CNG or chilled to liquid LNG) and sells it somewhere it is wanted. This page works out, for 18 real flares spotted by satellite, whether that trip pays, using only public data.

    Where the numbers come from

    • Gas & diesel prices: U.S. Energy Information Administration (EIA) API: Henry Hub daily spot, Gulf Coast diesel weekly.
    • Flare sites: World Bank / NOAA VIIRS satellite flare volumes (2012–2025), inside EIA basin outlines. Sites that flared in each of 2023–25.
    • Driving routes: OSRM on OpenStreetMap road data.
    • Costs: World Bank GGFR studies, ATRI trucking costs, DOE fuel properties, Hexagon & OEG container specs, BLS CPI.

    How it's built

    A PostgreSQL star schema fed by tested Python ingestion with data-quality checks; all netback logic is SQL views. This page is a static snapshot: it carries the SQL's outputs, and redoes only the final arithmetic for your what-ifs, checked against the SQL by automated tests. Read the code and write-ups ↗
